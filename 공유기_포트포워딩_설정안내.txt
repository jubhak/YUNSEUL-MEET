================================================================================
  YUNSEUL-PPT 공유기 포트포워딩 및 방화벽 설정 안내 가이드
================================================================================

본 문서는 YUNSEUL-PPT 호스트 PC에 외부(다른 네트워크, 외부 Wi-Fi, 모바일 LTE/5G 등)
참가자가 원활하게 접속하여 화면 공유 및 화상 회의를 이용할 수 있도록 공유기 포트포워딩
설정 방법을 안내합니다.

※ 같은 공유기 Wi-Fi/내부망에 있는 참가자끼리만 접속하는 경우에는 포트포워딩 없이도
   내부 IP(예: http://192.168.0.xxx:3000/)로 바로 접속하실 수 있습니다.


--------------------------------------------------------------------------------
1. YUNSEUL-PPT 필수 사용 포트 정보
--------------------------------------------------------------------------------
공유기 설정 페이지에서 아래 포트들을 호스트 PC(내 컴퓨터)로 포트포워딩해 주세요.

(1) 포트 3000 [프로토콜: TCP]
    - 용도: 웹 접속, 방 생성 및 참가, 실시간 채팅, 슬라이드 동기화 (HTTP / Socket.io)
    - 외부 포트: 3000 / 내부 포트: 3000 / 프로토콜: TCP

(2) 포트 44444 [프로토콜: UDP 및 TCP (UDP 필수, TCP 권장)]
    - 용도: 초저지연 화면 공유, 카메라 화상 및 마이크 음성 송수신 (WebRTC SFU 미디어 스트림)
    - 외부 포트: 44444 / 내부 포트: 44444 / 프로토콜: ALL(또는 UDP)

(3) [선택 권장] 포트 40000 ~ 49999 [프로토콜: UDP]
    - 용도: 다수 참가자 동시 접속 시 WebRTC 동적 미디어 포트 대역
    - 외부 포트: 40000~49999 / 내부 포트: 40000~49999 / 프로토콜: UDP


--------------------------------------------------------------------------------
2. 내 PC의 내부 IP(IPv4) 확인 방법
--------------------------------------------------------------------------------
공유기 포트포워딩 시 "내부 IP 주소"에 입력할 내 컴퓨터의 주소를 확인합니다.

1) 키보드의 [Windows 로고 키 + R]을 누릅니다.
2) 실행 창에 cmd 를 입력하고 엔터를 칩니다.
3) 검은 창에 ipconfig 를 입력하고 엔터를 칩니다.
4) 현재 연결된 네트워크(이더넷 또는 Wi-Fi)의 'IPv4 주소'를 확인합니다.
   (예: 192.168.0.25 또는 172.30.1.45 등)
   -> 이 주소가 포트포워딩 시 입력할 [내부 IP 주소]입니다.


--------------------------------------------------------------------------------
3. 공유기 제조사/통신사별 포트포워딩 설정 방법
--------------------------------------------------------------------------------

■ [ipTIME 공유기]
1) 웹 브라우저 주소창에 http://192.168.0.1 입력 후 로그인
2) [관리도구] 클릭
3) 좌측 메뉴: [고급 설정] -> [NAT/라우터 관리] -> [포트포워드 설정] 이동
4) 새 규칙 추가:
   - 규칙이름: yunseul-web
   - 내부 IP주소: 위 2번에서 확인한 내 PC IPv4 주소 체크/입력
   - 프로토콜: TCP
   - 외부 포트: 3000  /  내부 포트: 3000
   - [적용] 클릭
5) 두 번째 규칙 추가:
   - 규칙이름: yunseul-media
   - 내부 IP주소: 내 PC IPv4 주소
   - 프로토콜: ALL (또는 TCP/UDP)
   - 외부 포트: 44444  /  내부 포트: 44444
   - [적용] 클릭
6) (선택) 포트 범위 추가:
   - 규칙이름: yunseul-range
   - 프로토콜: UDP
   - 외부 포트: 40000 ~ 49999  /  내부 포트: 40000 ~ 49999
   - [적용] 클릭
7) 우측 상단의 [저장] 버튼을 눌러 공유기 설정을 영구 저장합니다.


■ [KT GiGA WiFi 공유기]
1) 브라우저 주소창에 http://172.30.1.254 입력 후 로그인
   (초기 아이디: ktuser / 초기 비밀번호: homehub 또는 공유기 스티커 참조)
2) [장치설정] -> [트래픽 관리] -> [포트 포워딩 설정] 이동
3) 내부 IP 주소에 내 PC IP 입력
4) 포트 3000 (TCP), 44444 (UDP/TCP) 각각 등록 후 [추가] 및 [적용]


■ [SK broadband 공유기]
1) 브라우저 주소창에 http://192.168.35.1 또는 http://192.168.219.1 접속 및 로그인
   (초기 아이디: admin / 비밀번호: 공유기 유선 MAC 뒷 6자리_admin 등)
2) [고급 설정] -> [NAT 설정] -> [포트 포워딩] 이동
3) 로컬 IP(내 PC IP) 지정 후 포트 3000(TCP), 44444(UDP/TCP) 등록 및 적용


■ [LG U+ 공유기]
1) 브라우저 주소창에 http://192.168.219.1 접속 및 로그인
   (비밀번호: 공유기 라벨의 웹 비밀번호/MAC 뒷자리 참조)
2) [네트워크 설정] -> [NAT 설정] -> [포트 포워딩] 이동
3) 내부 IP 지정 후 포트 3000(TCP), 44444(UDP/TCP) 등록 및 적용


■ [ASUS / 기타 외산 공유기]
1) 브라우저에서 공유기 게이트웨이(예: http://192.168.1.1 또는 http://192.168.50.1) 접속
2) [WAN] -> [Virtual Server / Port Forwarding] 이동
3) 포트포워딩 활성화 후 포트 3000(TCP), 44444(UDP/TCP) 규칙 추가 및 적용


--------------------------------------------------------------------------------
4. 가장 간편한 대안: [DMZ 설정] (강력 추천!)
--------------------------------------------------------------------------------
포트를 번호별로 일일이 등록하기 번거로우시거나 어려우신 경우,
공유기의 [DMZ 설정]을 이용하시면 모든 포트가 내 PC로 한 번에 개방되어 가장 편리합니다.

1) 공유기 관리자 페이지 접속
2) [고급 설정] -> [NAT/라우터 관리] -> [DMZ / Twin IP 설정] (ipTIME 기준)
   (타사 공유기: [보안 설정] 또는 [NAT 설정] -> [DMZ])
3) [DMZ] 선택 후 [내부 IP 주소]에 내 PC의 IPv4 주소를 입력하고 [적용]
-> 이렇게 하면 포트포워딩을 개별 등록하지 않아도 모든 연결이 즉시 통과됩니다!


--------------------------------------------------------------------------------
5. 외부 참가자 접속 링크 확인 방법
--------------------------------------------------------------------------------
포트포워딩 또는 DMZ 설정이 완료되면 외부 참가자에게 알려줄 링크를 생성합니다.

1) 네이버 또는 다음 검색창에 "내 아이피" 또는 "내 IP 주소 확인"을 검색합니다.
2) 표시되는 공인 IP를 확인합니다. (예: 121.130.45.67)
3) 외부 참가자에게 아래와 같이 링크를 전달합니다:
   http://[내 공인IP]:3000/
   (예: http://121.130.45.67:3000/)

이제 외부 참가자도 문제없이 방에 참가하여 화면과 소리, 화상 카메라를 이용할 수 있습니다.
